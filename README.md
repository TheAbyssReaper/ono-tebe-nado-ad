# Оно тебе надо

Учебная вёрстка аукциона вещей, в которые никто не верил.

## Открыть проект

Откройте `index.html` в браузере. Установка зависимостей и запуск сервера не требуются: изображения, шрифты и стили находятся в проекте и подключены относительными путями.

## Технологии

HTML5, CSS, Grid, Flexbox, локальный шрифт Raleway. Ширина страницы — 1100 px, согласно заданию первого спринта.

## Примечание

Это статическая учебная страница. Кнопка «Сделать ставку», ссылки карточек и ссылка «посмотреть больше» оформлены по макету; серверная логика аукциона в задание не входит. Меню ведёт к соответствующим разделам страницы.
